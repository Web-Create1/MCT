# Glossary

Terms a newcomer is likely to search for. For people, not loaded by any stage.

| Term | Meaning |
|------|---------|
| BLUF | Bottom line up front: the one-paragraph summary at the top of every document |
| CONOPS | Concept of operations: what a mission is for and how the crew will run it |
| Cross-track error | Sideways distance between the vehicle and the planned line, in metres (`xtrack_m`) |
| Failsafe | An automatic response by the flight controller to a fault, such as returning to launch |
| Geofence | A boundary the vehicle must not cross; crossing it triggers a failsafe |
| Hold | Vehicle stops and keeps station; for a USV, loiters at its position |
| PIC | Person in command: owns the go decision and the arming consent |
| QRC | Quick-reference card: one page for one contingency |
| RTL | Return to launch: the vehicle drives or flies back to its start point |
| Tamper-evident | Altering a log line breaks the hash chain, so the change shows. Not tamper-proof |
| Time to detect | Seconds from a fault's onset to the monitor's anomaly line. See `log-reading-guide.md` |
| USV | Uncrewed surface vessel |
| VO | Visual observer or lookout: watches the vehicle and the space around it |
