# UxS Mission Docs

Six stages, one document set per mission, every number traced to a request, a plan or a log line.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| New mission | `stages/01-intake/CONTEXT.md` | Turns a conversation into a one-page mission request |
| Concept of operations | `stages/02-conops/CONTEXT.md` | Purpose, concept, phases, roles, comms, environment, risks |
| Test plan | `stages/03-test-plan/CONTEXT.md` | Objectives, measures, procedure, pass criteria, go and no-go |
| Brief and preflight | `stages/04-brief-and-preflight/CONTEXT.md` | The crew brief and a one-page preflight card |
| Debrief | `stages/05-debrief/CONTEXT.md` | Timeline, anomalies, refusals, findings from an ops log |
| Training cards | `stages/06-training-qrc/CONTEXT.md` | One quick-reference card per contingency |

## Shared Resources

| Resource | Location | Contains |
|----------|----------|----------|
| Outlines | `references/*-outline.md` | The section list for each document |
| Crew and units | `references/crew-and-units.md` | Role codes and unit rules |
| Risk matrix | `references/risk-matrix.md` | Likelihood, severity, and the go threshold |
| Log reading guide | `references/log-reading-guide.md` | How to read an ops log for a debrief |
| Glossary | `references/glossary.md` | Terms for newcomers, never loaded by a stage |
